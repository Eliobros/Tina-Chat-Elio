# SocializeNow - Rede Social Moçambicana 🇲🇿

Uma rede social moderna e inovadora desenvolvida especificamente para conectar pessoas em Moçambique, promovendo a cultura local e criando uma comunidade digital vibrante.

## ✨ Características

- **Interface Moderna**: Design responsivo e intuitivo usando React e Tailwind CSS
- **Autenticação Completa**: Sistema de login e registro com validação
- **Feed Interativo**: Compartilhe posts, fotos e experiências locais
- **Perfis Personalizados**: Perfis de usuário com estatísticas e posts
- **Cultura Moçambicana**: Foco especial na cultura e localização moçambicana
- **Responsivo**: Funciona perfeitamente em dispositivos móveis e desktop

## 🚀 Tecnologias Utilizadas

- **Frontend**: React 18 + TypeScript
- **Estilização**: Tailwind CSS
- **Roteamento**: React Router DOM
- **Ícones**: Lucide React
- **Build Tool**: Vite
- **Formatação de Data**: date-fns com suporte ao português moçambicano

## 🛠️ Instalação e Configuração

### Pré-requisitos
- Node.js 16+ 
- npm ou yarn

### Passos para Instalação

1. **Clone o repositório**
   ```bash
   git clone <url-do-repositorio>
   cd socialize-now
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Execute o projeto em modo de desenvolvimento**
   ```bash
   npm run dev
   ```

4. **Abra no navegador**
   ```
   http://localhost:3000
   ```

### Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a versão de produção
- `npm run preview` - Visualiza a versão de produção
- `npm run lint` - Executa o linter
